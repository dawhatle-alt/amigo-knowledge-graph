# Upgrade method: centralized (CCM Agent Deployment) or local per host?

## Question

Upgrade method: centralized (CCM Agent Deployment) or local per host?

## Customer guidance

Centralized deployment upgrades multiple agents from one point; requires full Configuration + Operation privileges and staged packages.

## TSA guidance

Centralized recommended for fleets; verify privileges.
