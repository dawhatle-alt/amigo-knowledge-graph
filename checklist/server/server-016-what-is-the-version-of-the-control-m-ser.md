# What is the version of the Control-M/Server that is upgrading TO?

## Question

What is the version of the Control-M/Server that is upgrading TO?
NOTE: The latest Control-M version 9.0.22.000 is released and recommended to upgrade to this version.

## Customer guidance

AMIGO program ONLY covers the upgrade between supported versions.

## TSA guidance

If customer is upgrading to Control-M/Server to 9.0.21 on Windows, do discuss  KA 000402260 to resolve CTM-7300 - ess_key.txt is not created at 21.xxx upgrade
