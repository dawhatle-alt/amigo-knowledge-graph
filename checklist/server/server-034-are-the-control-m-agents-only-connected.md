# Are the Control-M/Agents only connected to a active Control-M/Server at any one time?

## Question

Are the Control-M/Agents only connected to a active Control-M/Server at any one time?

## Customer guidance

Control-M/Agent connected to two Control-M/Servers at the same time is not supported.
