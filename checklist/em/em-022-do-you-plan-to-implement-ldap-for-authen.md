# Do you plan to implement LDAP for Authentication, IdP or SSL Communication?

## Question

Do you plan to implement LDAP for Authentication, IdP or SSL Communication?

## Customer guidance

If YES, all configuration should be implemented after the completion of the Control-M/Enteprise Manager Upgrade.
NOTE: There is no need to disable existing LDAP, IdP or SSL implementation before the upgrade, unless otherwise stated in the upgrade document.

## TSA guidance

Do advise customer to open new case AFTER the completion of the AMIGO Review Case if required.
